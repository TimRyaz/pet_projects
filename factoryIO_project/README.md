В этой папке лежит проект сортировочного участка с производством из сырья с использованием программы Factory IO и Control IO.

Здесь происходит сортировка по цвету и весу, а также производство деталей из сырья с помощью станков с ЧПУ. Для запуска фабрики используется код функциональных диаграмм Control IO (аналог FBD). 

Ниже представлены ключевые блоки кода для выполнения тех или иных операций. Здесь рассмотрены блоки кода для сортировки по цвету, поочередного производства крышек и оснований (1 к 1), а также сортировки по весу.
